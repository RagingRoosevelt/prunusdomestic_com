Categories aren't declared anywhere: the groups, and the filter tree the script builds, come from the paths the shops use. Each shop is grouped under the root of its *first* category. Labels are the path text, _ as spaces, title case. {%- endcomment -%} {%- assign unsorted = "" | split: "" -%} {%- for state in site.data.local_retail -%} {%- for entry in state[1] -%} {%- assign unsorted = unsorted | push: entry[1] -%} {%- endfor -%} {%- endfor -%} {%- comment -%} Sorted by name ignoring a leading "The " (case-insensitive), so "The Enchanted Rose Emporium" files under E. Liquid can't sort by a computed key, so: build each shop's key (keys[i] goes with unsorted[i]), sort the distinct keys, then collect the shops back in key order. {%- endcomment -%} {%- assign keys = "" | split: "" -%} {%- for shop in unsorted -%} {%- assign lead = shop.name | downcase | slice: 0, 4 -%} {%- if lead == "the " -%} {%- assign key = shop.name | slice: 4, shop.name.size -%} {%- else -%} {%- assign key = shop.name -%} {%- endif -%} {%- assign keys = keys | push: key -%} {%- endfor -%} {%- assign sorted_keys = keys | uniq | sort_natural -%} {%- assign shops = "" | split: "" -%} {%- for key in sorted_keys -%} {%- for k in keys -%} {%- if k == key -%}{%- assign shops = shops | push: unsorted[forloop.index0] -%}{%- endif -%} {%- endfor -%} {%- endfor -%} {%- assign roots = "" | split: "" -%} {%- for shop in shops -%} {%- for pair in shop.categories.first -%} {%- assign root = pair[0] | split: "." | first -%} {%- assign roots = roots | push: root -%} {%- endfor -%} {%- endfor -%} {%- assign roots = roots | uniq | sort_natural %}

Local PDX businesses

I'm trying to shop as much as I can from local businesses. I've struggled on this mission because I've found it hard to discover local shops. I'd like to help you have an easier time of that by indexing local shops that I've discovered. If I'm missing something that should be on here, please let me know: .
{%- comment -%} A plain GET form to GitHub's new-issue page, so the fields become the query string: `template` picks the issue form in .github/ISSUE_TEMPLATE/, and `title` prefills its title. The shop list is hidden by CSS when a new shop is picked. The script sets `title` from the picked shop; without JS the form still opens the right template, just with its default title. Shop values are "State, City: Name" from the first location with a city, the format those templates ask for. {%- endcomment %}
