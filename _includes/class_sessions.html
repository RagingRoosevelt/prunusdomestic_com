{%- comment -%} Splits include.sessions (list of {date, registration_url, optional time, registration_text, location, location_text}) into upcoming and past. "Now" is build time: GitHub Pages only rebuilds on push, so a class moves to Past on the first push after its date, not on the day itself. Dates compare as YYYYMMDD integers; a class stays upcoming through its day. {%- endcomment -%} {%- assign today = site.time | date: "%Y%m%d" | plus: 0 -%} {%- assign sessions = include.sessions | sort: "date" -%} {%- assign upcoming = "" | split: "" -%} {%- assign past = "" | split: "" -%} {%- for s in sessions -%} {%- assign d = s.date | date: "%Y%m%d" | plus: 0 -%} {%- if d >= today -%}{%- assign upcoming = upcoming | push: s -%}{%- else -%}{%- assign past = past | unshift: s -%}{%- endif -%} {%- endfor %}
